# 分享卡收藏卡素材说明

> 方向：NFT 收藏卡（用户 2026-10-28 定）。渲染器仍为 `FieldwatchShareCard`，文案红线不变：
> 全部文案来自资源文件，渲染器本身不含任何文案；本目录素材只负责图像主体与边框材质。

## 1. 卡片语法（v3，2026-10-28）

**画布 720 × 1710**（高度由版式常量相加得出，不硬编码）。元素自上而下只有 6 样：

1. **边框**：12px 渐变环，代码画（见 §4）；外框四角**圆角 30**，导出 PNG 后四角透明。
   边框颜色即稀有度 / verdict 材质，并按稀有度分级装饰（§4）。
2. **主体图**：开槽 **696×1392**，与源图**同比例 1:2**（源图 1024×2048）；
   绘制时按 696/源宽 等比缩放后 1:1 贴合，**既不裁切也不留黑边**；顶部圆角 26、下直角。
   —— v2 的 cover / fit 与边缘拉伸填充全部作废：cover 会切掉横宽设备两端，fit 会留底色接缝。
3. **等级带**：**52 高**，左为编号（图鉴：`x / 611`；安防：扫描日期），右为 tier / verdict 词；
   文字 26 Bold，带色用饱和主色 + 对比文字色（§4），**不用渐变中间色**。
4. **名称**：**64 Bold** 居中；下一行 trait **28px `#C3CAD2`**（类别 · 最近出现 MM-DD）。
   其余信息一律不上卡。
5. **强制脚注**：琥珀色原句「只统计正在广播的设备；不广播的设备发现不了。」。
   —— **仅安防卡强制**；图鉴卡不设脚注（进度已在等级带左侧，重复即废话）。
6. **品牌行**：22px `#7D8A99`。

**下半区节奏**：名称 → trait → [脚注] → 品牌。
行距固定为「带底 + 84 → + 46 → + 92」，底边距 32；品牌不再钉在画布底部。
v2 的「细分隔线 / 整体下移」两种补空方案**均已作废**（v3 加高后不再有那块黑空）。

旧版元素（雷达、堆叠条、三色块、日期角标、辉光网格）已全部删除，不再复用；
任何档位都**不得**往卡面加回分数、进度条、堆叠条。

## 3. 规格

- 格式：WebP，质量 80，宽 1024（源图竖构图；展示区 696×688，cover 裁切，裁切焦点约在画面上半部 1/3–1/2 处）。
- 访问：rawfile 资源走 `$rawfile('sharecard/hero-audio.webp')`，Canvas 侧用 rawfile 内容解 PixelMap 后 `drawImage`。
- PNG 原图不进仓库，源图保管在 `~/workspace/your_files/分享卡素材/`，仅作重出底稿。

## 4. 边框渐变（代码画，0 张位图）

渐变用于 12px 边框环；等级带**不取中间色**，用同族饱和主色打底 + 对比文字色。

| 用途 | 边框渐变 | 等级带底色 | 带文字 | 分级装饰 |
| --- | --- | --- | --- | --- |
| 极稀有（金） | (138,109,27) → (245,217,122) → (138,109,27) | (201,162,39) | 深 (26,20,0) | **双环**：外圈 2px 亮线（二选一已选此方案，不加四角金点） |
| 稀有（紫） | (109,40,217) → (196,165,255) → (109,40,217) | (109,40,217) | 白 (242,245,248) | 主环 + 内圈 1px 细线（中间色 45% 透明） |
| 少见（蓝） | (29,78,216) → (127,178,255) → (29,78,216) | (29,78,216) | 白 (242,245,248) | 渐变方向**斜向**（左上 → 右下） |
| 常见（深钢） | (90,105,125) → (138,153,173) → (90,105,125) | (110,127,150) | 白 (242,245,248) | 素环（上下色由 (58,69,82) 提亮） |
| 可疑（橙） | (179,74,0) → (255,176,102) → (179,74,0) | (232,106,23) | 深 (26,15,0) | 素环 |
| 确认（红） | (185,28,28) → (255,138,122) → (185,28,28) | (185,28,28) | 白 (242,245,248) | 素环 |

**唯一事实源在代码**：`entry/src/main/ets/fieldwatch/platform/FieldwatchShareCard.ets` 的 `paletteOf()`。
本表只作说明，改色值 / 分级必须改代码，不要在文档与代码里各留一套。
