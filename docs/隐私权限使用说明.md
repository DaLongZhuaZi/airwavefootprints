# 隐私权限使用说明（供隐私协议引用）

> 依据：`entry/src/main/module.json5` 的实际声明，以及代码中的真实调用点。
> 权限等级数据来源：`sdk/default/openharmony/toolchains/lib/PermissionDefinitions.json`。
> 文中标注「预留 / 计划」的条目为已声明的使用范围，尚未落地实现。

本应用需要用户主动授权的权限共 **3 项**（系统设置里显示为三项），
均为 HarmonyOS 普通级（normal）权限，
**不涉及任何 ACL 受限权限，也不需要向应用市场单独申请。**

其中「运动数据」为后续功能预留，已在第三节写明其声明的使用范围。

---

## 一、设备发现和连接

**系统权限名**：`ohos.permission.ACCESS_BLUETOOTH`、`ohos.permission.ACCESS_NEARLINK`

> **说明**：系统设置里本应用只有一项「设备发现和连接」，它**同时管理蓝牙与星闪**。
> 因此本应用内也只显示这一项，不会出现单独的「星闪」权限项。

**用途**

用于接收周围蓝牙低功耗（BLE）设备主动广播的信号，以便在「实时」页面展示附近的无线信号源。

**具体做什么**

- 以**被动监听**方式接收 BLE 与星闪（NearLink）广播包，读取其中的公开信息：设备地址、设备名称、信号强度（RSSI）、
  广播的服务 UUID、厂商数据、发射功率等。
- 将这些广播信息与内置的特征库比对，用于判断设备类型（如耳机、手环、追踪器、信标等）。
- 用于「与你同行」判定与关注目标的提醒。

**不做什么**

- **不连接**任何设备，**不配对**，**不读写**设备数据。
- **不注入**、**不干扰**、**不控制**任何被观测设备。
- 本应用只使用系统的扫描接口监听广播，不建立任何蓝牙或星闪连接。

**关于星闪设备地址**：星闪的**真实 MAC 地址属于系统级权限，本应用不申请、也无法获取**。
界面上显示的星闪地址可能是系统分配的匿名标识、**可能随时间变化**，
因此本应用不将其作为稳定的设备身份使用。

**数据去向**

全部观测数据仅保存在设备本地。除用户主动发起的导出或分享外，不会上传到任何服务器。

**使用时机**

仅在你位于「实时」页面且扫描进行中时使用；可在设置中随时关闭扫描。

**拒绝授权的影响**

无法接收 BLE 广播，「实时」页面只能显示 Wi-Fi 接入点。其余功能不受影响。

## 二、位置

**系统权限名**：`ohos.permission.APPROXIMATELY_LOCATION`（大致位置）

**用途**

在你主动开启「记录手机听到设备的位置」后，为每一条观测结果附加位置标记，
并据此绘制本机移动轨迹。

**具体做什么**

- 仅在上述开关打开时读取**大致位置**（非精确定位）。
- 把位置与当次观测关联，用于「轨迹画布」和带位置的观测记录。
- 用于「与你同行」判定。

**不做什么**

- **不做后台定位**。应用不在后台时不会获取位置。
- 不持续追踪，只在记录观测时按需取一次，并对短时间内重复取值做缓存。
- 位置数据不会上传到任何服务器。

**使用时机**

仅在你打开「记录手机听到设备的位置」开关后使用；该开关默认关闭。

**拒绝授权的影响**

观测结果不携带位置信息，轨迹画布为空。其余功能不受影响。

## 三、运动数据

**系统权限名**：`ohos.permission.ACTIVITY_MOTION`

**用途**

用于识别你当前的运动状态（静止 / 步行 / 骑行 / 驾车），辅助「与你同行」判定的准确性。

**具体做什么**

- 读取系统提供的**运动状态类型**（例如「正在步行」「正在驾车」），
  用于判断设备是否真的在与你一起移动。
- 结合信号强度的连续性，区分「同行设备」与「恰好同时出现的固定设备」，减少误报。
- 例如：驾车时沿途持续出现的设备更可能是随行设备，而步行时则更可能是固定信标。

**不做什么**

- **不采集原始加速度、陀螺仪等传感器数据**，只读取系统已经判定好的运动状态类别。
- **不做健康监测**，不记录步数、卡路里或任何身体指标。
- 运动状态数据不会上传到任何服务器，也不与观测记录一并长期保存。

**使用时机**

仅在「实时」页面扫描进行中、且「与你同行」判定运行时读取。

**拒绝授权的影响**

「与你同行」判定退化为仅依据信号强度连续性，准确度下降。其余功能不受影响。

> **说明**：该权限为后续功能预留。当前版本已在清单中声明其使用范围（如上），
> 实际调用将在「与你同行」增强版本中落地。

## 附：不需要用户授权、但同样在隐私协议中建议提及的权限

以下权限为系统级（system_grant），安装即授予，不会向用户弹出授权窗口，
但其中部分涉及数据处理，建议在隐私协议中一并说明：

| 权限 | 系统设置里的名称 | 用途 |
|---|---|---|
| `ohos.permission.GET_WIFI_INFO` | 应用联网 | 读取周围 Wi-Fi 接入点的名称、频段、信号强度。**不会连接任何网络** |
| `ohos.permission.SET_WIFI_INFO` | 应用联网 | 配合 Wi-Fi 扫描使用 |
| `ohos.permission.INTERNET` | 应用联网 | **仅在用户主动点击「更新内置目录」时**访问网络下载最新签名目录；应用不在后台联网 |
| `ohos.permission.ACCELEROMETER` | 应用获取设备方向 | **当前未使用**，建议移除声明 |
| `ohos.permission.DETECT_GESTURE` | — | **当前未使用**，建议移除声明 |
| `ohos.permission.ACCESS_BIOMETRIC` | — | **当前未使用**，建议移除声明 |

> `ACTIVITY_MOTION` 按用户决定保留，其声明的用途见第三节（后续功能预留）。
| `ohos.permission.KEEP_BACKGROUND_RUNNING` | — | 后台持续扫描时保持运行 |
| `ohos.permission.PUBLISH_AGENT_REMINDER` | 通知 | 关注目标首次出现时发送系统通知 |
| `ohos.permission.VIBRATE` | — | 寻线模式的振动反馈 |

## 附：未来将新增的权限

「单个信号跟踪模式」的测向功能将使用：

- `ohos.permission.GYROSCOPE`（陀螺仪）—— 系统级权限，**不弹授权窗**，无需用户同意。

该功能通过提示用户缓慢转动设备、记录「朝向角 ↔ 信号强度」曲线来估算信号的**相对来向**。
受限于手机单天线，**无法给出绝对方位**，协议中不应声称可测定方向。
