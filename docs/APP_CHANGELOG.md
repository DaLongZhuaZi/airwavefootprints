# 应用更新日志 · 电波足迹

> 面向用户的版本变化记录。应用内「设置 → 关于 → 更新日志」与本文件同源，
> 数据源为 `entry/src/main/ets/fieldwatch/domain/FieldwatchChangelog.ets`。
>
> 维护约定见 `.rules/skill-app-release.md` §4.1：版本号（`versionName` 或 `versionCode`）
> 任何变化都必须同步更新应用内更新日志，否则用户在应用里看到的仍是旧内容。

## 版本号口径

`versionCode` = `major × 1000000 + minor × 10000 + patch × 100 + build`

| versionName | versionCode | buildVersion |
|---|---|---|
| 1.1.1 | 1010101 | 7 |
| 1.1.0 | 1010000 → 1010001 | 5 → 6 |
| 1.0.0 | 1000000 → 1000004 | 1 → 4 |

## [1.1.1] - 2026-10-28

### 实时页

- 改成「今天怎么样」的六张卡片：今日结论、近 7 日趋势、周边 Wi-Fi、设备图鉴进度、更多工具，
  专业雷达收进折叠区（雷达、分类、品牌筛选能力全部保留）
- 今日结论卡的关键数字可点，分别进入雷达、新面孔清单、Wi-Fi 体检
- 「安全检查」入口统一改名为「安防扫描」（文案与状态提示同步）
- 平板横屏改成双列卡片；出现分栏（右栏打开）时自动回到单列，切换带 240ms 过渡动画

### 工具箱

- 拆成信道分析、反追踪、找东西三个独立页面；工具箱本身只做入口，顶部新增搜索
- 横屏下工具箱与各子页改为「左侧保留入口 + 右侧显示内容」的分栏
- 所有入口左边缘对齐（「主动扫描授权」此前按二级入口缩进，看起来比别的空出一截）
- 所有子页内容区统一为一个居中大标题（与寻踪页同一套版式，不再有副标题）
- 设置页移除「主动扫描」入口，统一从工具箱进入

### Wi-Fi 体检

- **修复频段错配**：原来无论当前连的是哪个频段，结论卡都拿 2.4G 的数据下判断；
  现在按当前连接 AP 的频段取数据，该频段没数据时明说「暂无扫描数据」，不回落到别的频段
- 新增顶部网络概况卡（SSID + 频段 + 信道 + 信号 + 一句话结论）
- 底部「去信道分析」带当前频段参数，进去直接落在同一频段

### 安防扫描

- 主动探测改为可选附加项：勾选时才弹授权说明（能力清单 + 暴露面 + 数据去向），
  取消则勾选自动回退；ACL 机制本身未改动
- 扫描过程显示阶段条、实时计数与雷达扫动动画，可随时取消
- 结果改为每台可疑设备一张风险卡片（风险色条 + 证据分项 + 查看详情/忽略），
  并补上设备类型构成条与「与上次相比」的变化
- 人工排查清单默认收起，标题行显示进度
- **分成两种模式**：普通扫描只被动听 30 秒、**结果不进历史**；安防扫描 60 秒、可选主动探测并记入历史
- **修复「可疑」计数不实时**：此前扫描过程一路显示 0，结束却报出好几台；
  现在过程与结果用同一套判定，过程数必然等于结果数
- **修复点 30 秒扫描时弹「BLE 扫描失败」横幅**（应用已在持续扫描，重复启动被系统拒绝）

### 设备图鉴

- 格子按类别显示专属图标，补上出现次数与点亮日期
- 新增搜索与三档筛选（全部 / 已点亮 / 未点亮）
- 详情改为底部 sheet；点亮新设备时星星弹入动画 + 弹层缩放淡入
- 补上无人机、查找器标签、其他三类设备类型的图标（此前是空白格子）
- **修复解锁弹层类别栏空白**，以及每次渲染刷 `Invalid resource ID` 日志的问题

### 新面孔

- 每行补上首次出现时间、信号强度与风险提示
- 新增「查看详情」「这是我家的」「拉黑」三个动作
- 按今日 / 本周分组，今日置顶

### 分享卡（收藏卡）

- 重新排版：主体图按源图 1:2 铺满、文字放大一档、四角圆角、边框按稀有度分级
- 安防档名称改用等宽字体；trait 去掉重复的「厂商」；查找器主体图视觉居中
- **修复生成失败**：导出尺寸改为自适应降级，自动取本机能编码的尺寸

### 特征库

- 列表在横屏平板上铺满屏幕底部，不再留出一条空白

### 后台与稳定性

- **修复切到后台时反复报 9800005**（长时任务被重复申请）：首次申请加了并发守卫，
  后台路径只刷新通知、不再发起首次申请
- **修复切后台时重复停止 BLE 扫描**产生的告警：停扫加状态守卫，第二次成为空操作
- 启动日志不再出现数据库迁移的 `ALTER` 报错（迁移前先查列是否存在）
- 首次运行自动从内置目录生成签名目录，不再误报「本地目录损坏」

### 启动引导

- **修复「要不要提醒你」页开关占满全屏的布局错误**
- 补充提醒机制说明：什么时候会响、什么时候不会、为什么头几天提醒偏少

### 动画与交互

- 9 个工具子页补齐与特征详情页一致的入场/退场动画（右侧 40vp 滑入 + 淡现）
- 工具箱与特征库的双列 ↔ 单列切换加 240ms 过渡
